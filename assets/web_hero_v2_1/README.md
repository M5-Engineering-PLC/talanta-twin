# web_hero_v2_1 bundle (internal, private)

The web_hero_v2 bundle with three changes (2026-10-26):
- G2 trees: measured tree albedo and crown normals for the instanced tree protos, impostor atlas rendered as albedo (blender/web_hero/export_web.py, 740638e).
- The look block (manifest "look", from blender/web_hero/look_v2.json): view transform, look, exposure per view, the OCIO curve and the compositor values.
- G8 phone variant: models_phone/talanta_{hero,site}_phone.glb and manifest_phone.json; phone tier 1 is 37.65 MB of the 40 MB budget.
The bake, the panoramas and the ground tiles are those of web_hero_v2.
Labels: estimated geometry and colours (parameter ledger). Traffic and any people are Visualization. No reference frame is used as a texture.
