# assets/web_hero_v2 (orphan branch, binaries only)

The web_hero_v2 bundle from work order engineering/cloud_web_hero_v2_2026-10-24.md (W3 and W4), built on the
cloud runner from blender/out/frozen_FK.blend (finished state, look layer day). Code, notes and a copy of the
manifest are on wo/web-hero-v2: blender/web_hero/WEB_HERO_V2.md and blender/web_hero/web_hero_v2_manifest.json.
The baked maps it was built from are on assets/web_hero_v2_bake.

- models/: talanta_hero.glb and talanta_site.glb (meshopt geometry, KTX2 textures)
- ground/: 61 KTX2 ground tiles and tiles.json
- env/: 07:30 (morning_golden) and 17:30 (evening_golden) panoramas, 8K EXR and 2048 HDR, with render logs
- manifest.json: every file with bytes and sha256; 164,571,833 bytes against the 250,000,000 byte budget

Estimated geometry and colours (parameter ledger). Traffic and any people are Visualization. No reference frame
is used as a texture. Internal, private repository only.
