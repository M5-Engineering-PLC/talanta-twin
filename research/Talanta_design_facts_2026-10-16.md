# Talanta Stadium design facts

Date: 2026-10-16
Status: sourced from press reports. Not verified against drawings.
Use: reference for the 3D model. Press reports can be wrong, so check each fact against the frame set before you model it.

## Facts

| Fact | Source |
|---|---|
| Capacity: 60,000 seats. An early concept had 50,000 seats and a Maasai shield shape. The final design is a more usual oval. | StadiumDB design page |
| Eight primary gates. Each gate has smaller access points. The gates use the shield motif. | Capital FM, Dec 2025 |
| The facade uses the shields and spears from the Kenyan flag. | Capital FM, Dec 2025 |
| The seats follow a gradient of green, red and black, from the Kenyan flag. | Capital FM, Dec 2025 |
| The roof is a fixed canopy. The plan dropped a retractable cover. | Kenyans.co.ke |
| Hydraulically tensioned steel cables hold up the lightweight roof canopy. | Capital FM, Dec 2025 |
| Project architect: Major Victor King'e, for the Ministry of Defence. Main contractor: China Road and Bridge Corporation. | Press reports in the search results |
| An architectural scale model of the stadium exists. A photo caption shows it with the main gates. | Citizen Digital |

## Notes against the frame set

- The frames show red seats with black seats in some rows. Green seats are not yet confirmed in a kept frame.
- No official 3D model or virtual tour was found. The one 3D video in the frame set (oL3wsPsx4Jw) is a third-party render and does not match the real stadium.
- The 2023 design video VoDsWtlMQZ0 shows the old shield concept. Do not use it for geometry.
